# rainfall-agriculture-powerbi-dashboard
📌 Project Overview

This project analyzes the relationship between rainfall patterns and agricultural productivity using data analytics techniques.

The goal is to understand how rainfall variations impact crop yield and to generate insights that can support better farming decisions and resource planning.

🎯 Objectives

Analyze rainfall trends over time

Study the impact of rainfall on crop production

Identify patterns and correlations between rainfall and yield

Build visual dashboards for insights

Provide data-driven recommendations for agriculture planning

📊 Key Insights (Example)

Seasonal rainfall strongly influences crop yield.

Excess rainfall in certain months reduces productivity.

Some crops show higher resilience to rainfall fluctuations.

Year-on-year rainfall variation impacts overall agricultural output.

🛠️ Tools & Technologies Used

Excel – Data cleaning and preprocessing

SQL – Data querying and transformation

Power BI / Tableau – Dashboard creation and visualization

Python (Optional) – Data analysis & correlation modeling

📂 Dataset Description

The dataset includes:

Year

Region/State

Monthly Rainfall (mm)

Crop Type

Crop Yield (tons/hectare)

Area of Cultivation
